# Python

Hands-on Python notebooks on data analysis and machine learning, plus a small web app.

## Folders

| Folder | What's inside |
|--------|---------------|
| [`data-science-notebooks/`](data-science-notebooks) | 14 Jupyter notebooks and 1 Python script: functions, dataframes, data visualization, linear and multi-variable regression, cost functions, gradient descent, learning rate, and unsupervised learning (PCA, clustering) |
| [`flatmates-bill/`](flatmates-bill) | Flatmates Bill web app: splits a shared bill between flatmates by days spent in the house and generates a PDF report |

## Data files

Some notebooks read CSV files that are not in this repository. Put them in `data-science-notebooks/` before running them:

| Notebook | File |
|----------|------|
| `Hands-on dataframes.ipynb` | `lsd-math-score-data.csv` |
| `Working with objects to analyse data.ipynb` | `lsd-math-score-data.csv` |
| `Linear Regression.ipynb` | `9249290-cost-revenue-clean.csv` |
